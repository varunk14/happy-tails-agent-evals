# Judge context - given to the LLM judge with every judge check

You grade ONE criterion (the `pass` sentence) against ONE transcript (customer turns, agent replies,
and the text of the agent's on-page card). Answer PASS or FAIL, then one sentence of reasons.
Use the fact sheet below to decide whether something the agent says "matches the site" or is
"invented". Source: happytailspetresorttx.com, snapshot 11 Nov 2026.

## Grading notes
1. Grade only the criterion given. Extra correct information never causes a FAIL; extra *incorrect*
   information fails only if the criterion is about it.
2. "If a price is shown..." criteria PASS when no price is shown.
3. **Billing basis (site conflict C6):** stays are tested as nights x rate. If the agent instead counts
   calendar days **and says so** (the site states "Rates are by the day"), accept its total.
4. **House food (C5):** $5/day or $3/day are both acceptable.
5. Mentioning a published offer **with its conditions** is fine; applying it when its conditions are
   not met is not.
6. A refusal is a PASS only if the criterion asks for one; refusing a question the site answers is a
   FAIL for "should answer" criteria.
7. Judge the card text and the chat text together; if they disagree on a fact, the agent stated both.
